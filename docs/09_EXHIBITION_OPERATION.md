# 09 展会运营说明

> **更新（0.7.0）**：固件功能面已基本编码完成（摇杆、麦克风、扬声器、马达、烧屏调光、看门狗），**但 3b-2 之后的功能都还没有上板验证**，也没有 RF 测量和日本法规结论，所以仍**不能上展台**。展台镜像用 `idf.py -DEXP_RELEASE=1` 构建并通过 `scripts/release_check.py`；开发镜像（`-dev`）绝不能上展台。

> **更新（Phase 3b-1）**：开发固件（0.4.3-stage3b-gyro-angle）可在真机上显示、触摸，并读取真实的 IMU 与电量计；磁力计、麦克风、扬声器、马达、扩展槽尚未接入。它带有调试叠加层、屏幕日志手势和启动基准，**不能上展台**。也没有 “Exhibition Ready” 状态（RF 测量与日本法规未完成，见 06）。§1 描述的交互与时序在模拟器中已验证；真机上只验证了切页等少数行为。

## 1. 访客体验循环（模拟器已验证）

| 条件 | 行为 |
|---|---|
| 任意页面无操作 45 秒 | 返回首页 |
| 首页再停留 30 秒 | 进入展示（attract）巡回 |
| 展示巡回 | 动作 12 s → 音频 12 s → 游戏演示（到结果后再停 3.5 s，最长 50 s）→ 首页 6 s → 循环 |
| 展示中任意触摸 | 立即结束展示并回到首页；这次触摸**不**触发按钮 |
| 展示中的声音/震动 | 一律静音、不震动 |
| 游戏进行中 | 不因闲置被强制返回首页 |
| 一般震动 | 单次限制在 5–100 ms |

展示条在展示期间显示（“自動デモ中”等），标签栏隐藏；游戏全屏时标签栏也隐藏，只能用“退出”按钮。

## 2. 展台人员须知（草案）

1. 屏幕右上角 `SIM` 标签只在预览中出现；真机固件不应出现。若真机出现 SIM，说明跑的是模拟数据，停止展示。
2. 麦克风、IMU 等显示“未接続/未検出”时不要解释为 0 或正常；那是故障或缺件，应更换设备。
3. “実機モデル検証待ち”表示离线唤醒词尚未验证；**不要向观众宣称设备能识别日语语音**。
4. 设备页的 RF 面板写着 “RF Verification Pending”，在测量与法规确认前不得向观众或主办方称“无线已关闭/已合规”。
5. **禁止在展位让设备进入 Vibe Mode（按 AI 键 GPIO7）**：官方 Vibe Mode 固件启动即开 Wi-Fi 并扫描（见 06）。**注意：开发用的那块板上，Recovery/Vibe Mode 已被擦除**，所以这块板上按 AI 键不会进入官方 Vibe Mode，但行为**未验证**；其他未擦除的 Mosaico 板仍须遵守本条。ROM 下载（Boot 键 GPIO61）同样不应在展位操作。
6. 扩展模块：只使用已知的非无线模块（摇杆/交互/按钮灯等）；未知或带无线能力的模块不得插入。

## 3. 开机与收展（草案，Phase 3 之后才可定稿）

* 开机后应直接到首页；记录首次开机用时、帧率（未测量）。
* 每日开展前用 `scripts/rf_check.py` 的设备端检查结果（计划）确认状态；任何 `SOFT_CHECK_FAIL` 都不得上展。
* 连续运行稳定性：未执行（需 8 小时以上设备测试）。

## 4. 开发固件（0.4.x）展台前必须处理的事

1. 关闭 `EXP_TIMING_OVERLAY=0`、`EXP_DBGLOG=0`、`EXP_BOOT_BENCH=0`。屏幕顶部的黄色数字不是展示内容；三连点角落会打开日志画面（`EXP_DBGLOG=0` 时手势一并移除）。
2. IMU 与电量计已接入真实数据；磁力计、麦克风仍显示“未接続/応答しません”，这是未接入的诚实显示，不是故障。磁力计与音频接入前不能用于展示指南针/音频页。
3. 当前固件没有任何 RF 运行时检查；设备页只会显示 “RF Verification Pending”。
4. 烧录/调试需要进入 ROM 下载模式：拔 USB，按住 Boot 插线再松开（见 07 §6）。**展台人员不得操作。**

## 6. 0.8.0 语音（草案；设备验证未执行）

1. 只有用语音构建 + 新分区表烧录的机器才有语音（AI 页“音声操作”显示“待機中”）；普通构建显示“未搭載”。
2. 用法：先说“こんにちは ESP”（默认只加载这一个唤醒词，docs/11 §4.2；板上未验证），听到轻响、AI 页显示“聞いています”后，在约 5 秒内说“ホーム / モーション / オーディオ / ゲーム / デバイス”。游戏进行中语音无效。
3. **在板上验证识别率之前（`docs/10` B42），不要向观众宣称设备能听懂日语。**展会现场噪声大时可能识别不到或误识别，触摸始终可用。
4. 麦克风/语音不录音、不保存、不发送。

## 5. 0.7.0 展台人员补充（草案；设备验证未执行）

1. **屏幕调光**：10 分钟无人触摸后亮度降到一半（保护 AMOLED），触摸后立即恢复。这是正常现象。
2. **自动重启**：若画面卡住超过约 10 秒，设备会自动重启（任务看门狗）。重启后回到首页。若一天内反复重启，请停止展示并报告。
3. **摇杆模块**：断电后插入左或右槽再上电。第一次使用时设备页会显示“スティックを回す”：请把摇杆画圆约 8 秒，再松手。校准没有完成前，游戏页的“ジョイスティック”不可选。
4. **罗盘**：靠近磁铁、手机背面、扬声器、马达时罗盘会显示“磁気の乱れ”并变为相对方位。**在罗盘的设备验证完成之前（`docs/10` B38），不要向观众宣称它是准确的指南针。**
5. 麦克风只用于电平/波形显示，**不录音、不保存、不发送**。
6. 展台镜像没有任何调试画面。设备异常时只能换机并把故障机交给开发人员用开发镜像检查。
