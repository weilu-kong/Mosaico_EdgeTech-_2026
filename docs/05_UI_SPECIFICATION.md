# 05 UI 规格（Phase 2 实现）

全部为日文界面，480×480 RGB565，30 Hz 更新。字形：Noto Sans CJK JP（Regular/Bold）子集，SIL OFL 1.1，由 `tools/gen_font.py` 根据 `main/exp_strings.h` 生成。**规则：任何会显示的字符串必须是 `exp_strings.h` 中的宏**，否则字体里可能缺字（布局检查器会报“缺字”，`run_all_tests.sh` 校验字体可复现）。

## 4. 状态与诚实显示

* **SIM 标签**：Host 预览中永久显示，表示所有传感器值为合成。
* 传感器缺失/故障：对应区域显示“未接続”或错误说明，**不显示 0 之类的假值**。
* 磁力计未校准：偏航显示“ヨーは相対値”，指南针标注“未校正”，直到完成完整校准才显示“校正済み”。
* 内存：未知时显示 `--`。
* AI：显示“実機モデル検証待ち”；无识别结果；VAD 标注为经典 DSP。
* RF：设备页 RF 面板固定文字含 “RF Verification Pending”，并带声明“法規認証・RF測定の結論ではありません”。**不出现 “Exhibition Ready”**。

## 5. 展示（attract）与触摸

* 触摸唤醒：展示中第一次触摸只返回首页，不触发按钮。
* 按下后滑出按钮区域取消点击。
* 展示中静音、不震动。
* 倒计时、游戏结果、摇杆/触摸/倾斜三种输入的回退逻辑：若所选输入不可用，则动态回退并在 JSON 状态中报告实际输入（`input`）。

## 6. 自动化布局检查（布局记录器）

对每个画面记录：文字被裁切、文字溢出盒子、元素重叠（含 keepout 区）、触摸目标小于 44 px、缺字形。22 个画面（含长文本压力、无传感器、故障、展示条等）**0 个问题**（`evidence/screenshots/layout_report.json`）。

> 注意：布局检查只证明模拟器渲染的几何关系，**不证明**在真实 CO5300 面板上的色彩、亮度、观感，也不证明触摸的实际手感。

截图见 `evidence/screenshots/`，总览为 `evidence/screenshots_contact_sheet.png`。
